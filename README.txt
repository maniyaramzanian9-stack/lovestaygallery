LoveStay Gallery — Static Demo

این بسته برای انتشار به‌صورت سایت استاتیک (از جمله GitHub Pages) آماده شده است.

شروع: فایل index.html را باز کنید.
صفحات: index.html, products.html, cart.html, account.html, profile.html, admin.html

نکته‌ها:
- این نسخه بک‌اند، PHP، پایگاه داده، ورود واقعی یا پرداخت ندارد.
- ورود نمایشی: کد آزمایشی ۱۲۳۴۵۶ است؛ هیچ پیامکی ارسال نمی‌شود.
- سبد خرید و برخی تغییرات نمایشی در localStorage مرورگر ذخیره می‌شوند.
- ثبت سفارش فقط یک نمونه محلی می‌سازد و هیچ پرداخت یا سفارش واقعی انجام نمی‌شود.
- پنل مدیریت صرفاً نمایشی است و نباید برای مدیریت فروشگاه واقعی استفاده شود.

برای GitHub Pages، محتویات ZIP را در ریشه مخزن قرار دهید و در Settings > Pages شاخه main و پوشه /(root) را انتخاب کنید.
